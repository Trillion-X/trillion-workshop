# Local narration source

This is the media-composition owner's adopted narration library, derived from
Showtime 0.4.5 under its retained MIT license, copyright 2026 Favio Vazquez.
`source-adoption.json` records the exact migration inputs and local adaptations.
The migration tree remains readable evidence; this caller never executes it.

`author-voice-script.mjs` owns checked copy input, admitted execution and output
binding. `produce.py` uses the adopted script, local alignment, mastering and
readback code. Python dependencies and model files remain installed runtime
dependencies. The shared computer-programs owner selects a compatible interpreter
from declared paths; this source installs or downloads nothing.

The Trillion voice engine delegates voice lookup, cached reference recovery and
synthesis to the existing `computer/speak.mjs` owner. Narration requires an exact
voice id and fails when that voice cannot run. Other callers keep the speaker's
existing fallback behavior. Waveform cache reuse is disabled for this bridge,
because a voice's model or reference can change without changing its id.
The optional source `place` names the speaker's existing context and is preserved
in the bound native script. It selects that context through the existing speaker
API; this library does not infer a place or search other cached voice lists.

Only adopted engine modules next to the registry can load. Installed Showtime
plugins, ambient engine paths, old launchers, renderers, installers and MCP
services are outside this source route. New narration cache identities call
Trillion's existing BLAKE3 owner. Retained SHA-256 fields identify upstream model
checksums only; this producer does not create internal SHA-256 identities.

The focused readback tests cover this library's textual matcher. They do not
qualify the old video QA, phone, receipt or rendered-output consumers. Mocked
speaker/producer tests do not establish real synthesis, listening, selected-voice
identity by sound, author approval or learner outcomes. Those require distinct
actual consumer evidence.

`produce.py asr inspect --lang en` composes the adopted transcription model
declarations with their existing local model-marker and Python/component
readiness readers. It never loads a speech model, downloads weights or installs
dependencies. Unreadable metadata remains unknown, rather than proving absence.
The report also exposes the readback owner's preferred installed alternate.

`produce.py asr recheck <voice-directory> --model <declared-alias> --line <id>
--line <id> -o <fresh-evidence-directory>` hears only the selected existing line
clips. It preserves timeline order, requires local readiness, forces a fresh
recognition without source-word prompting, and binds the original timeline,
programme waveform, readback and selected clips through the shared BLAKE3 owner.
An existing output directory, a path leaving the voice directory, or a changed
bound input is refused. Recognition failure keeps its separate recoverable epoch.
This operation supplies recognition evidence; it never clears a source warning
or claims that recognizer agreement proves acoustic correctness.
