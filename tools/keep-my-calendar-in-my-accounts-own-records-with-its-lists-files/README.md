# tools/keep-my-calendar-in-my-accounts-own-records-with-its-lists-files/

Keep my calendar in my account's own records, with its lists, files, connections and model, never in a second calendar store.

Moved here byte for byte from Trillion-X/trillion by `tools/move-code-between-trees`; `moved-from.json` names each file's source path and commit and the identity of its bytes there and here. Trillion-X/trillion imports these files from this package. The folder keeps the source tree's own paths under it, so the files import each other as they did.

`src/task-proposals.mjs` (REA finding F-0091: an AI or a rule suggests tasks, the person accepts them before they become tasks) changes tasks through `tools/plan-tasks-and-todo-lists/calendar-tasks.mjs`. `test/task-proposals.test.mjs` is old trillion's test of it, at the tag `old-trillion-before-worker-retire`, with its import paths set to the Workshop copies of the local store, the lists and calendar tasks.
