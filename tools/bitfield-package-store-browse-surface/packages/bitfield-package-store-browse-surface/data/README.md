# Browse Surface Data

Browse-surface data configures the package-store surface.

- `browse-surface-config.json` stores filters, hero scenes, local package-file
  request defaults, and search suggestions.
- `action-capability-records.json` stores action-capability data.
- `install-destinations.json` stores package-owned destination choices when a
  local owner publishes them.

The active config names current owners. The stale
`bitfield-package-store-install-surface` owner is not an active config target.
