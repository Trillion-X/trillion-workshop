# Content Media Evidence

This owner also defines `canonical-artifact-ref/v1`: retrieval identity and
retrieval mode are explicit, integrity is independent, and browser delivery is
accepted only through a current relation-scoped access decision. Local files,
connected sources, generated bytes, and chunked outputs all materialize through
the same `cas-store.materialize-bytes` Envelope target. No source in this
package recognizes legacy `cas_address`/`multihash` fields any more, and
the `an-artifact-source-may-not-name-a-retired-byte-identity` rule this package
declares in `things-to-store-and-run.json` enforces that with no exceptions.
The declared runner collects it, so it is checked with every other source rule
in the corpus rather than by a walk this package maintains itself;
`tests/artifact-rules-fire-on-the-thing-they-forbid.test.mjs` proves it fires.

The migration owner that used to hold that exemption was deleted on 2026-09-05,
along with its target, entry, entry bytes and descriptor. It had no caller, no
carrier that could address it, and its one DATA pointer (`legacy_migration_target`)
had no reader. Its producer was already gone. If a relation record carrying
`cas_address`, `multihash` or `stored_bytes_address_label` under `source_ref` is
ever found, the repair is a DATA operation through `engine.operation.write-batch`
with basis proof, not a shipped target: rematerialize the bytes through
`cas-store.materialize-bytes`, write the successor, read it back, and only then
retract the legacy fields in a second guarded revision. That ordering is the part
worth keeping, and it is recorded here rather than in code because it runs once.

Shared content-media workflow helpers for media-oriented Bitfield Studio packages.

## Rules

- `do-work` is a declared public source root for packages that compose the
  shared content-media workflow request helpers.
- File picker output is descriptor data, not the media byte transport.
- Selected local media paths are staged with `compute.process` outputs using addressed chunk storage.
- Downstream media workflows receive `blob_ref` inputs. They do not receive raw picker bytes or direct local path process inputs.
- compute.process inline-source encoding is owned by `@bitfield/runtime-kit/protocol`, not this shared content-media package.
- `reference-grounded-screen-contract.md` records that this helper has no direct customer-facing surface.
- `proof/mobbin-reference-proof.md` and `proof/visual-proof.md` delegate visual proof to the consumer packages that render selected media and evidence flows.
