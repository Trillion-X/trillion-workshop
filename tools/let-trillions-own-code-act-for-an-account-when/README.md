# tools/let-trillions-own-code-act-for-an-account-when/

Let Trillion's own code act for an account when no person is signed in, with a short-lived proof only the account's own policy can make.

This folder has no row yet. Wiring them into a row is adapting them, in a commit that names `moved-from.json`.
