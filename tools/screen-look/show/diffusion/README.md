# Diffusion range appearance

Scoped semantic colors for the actual Diffusion Studio slider in packages/ui/show/diffusion. The build compiles the original component's Tailwind classes into the `.diffusion-range` scope; this stylesheet supplies colors, label spacing, touch target extension and reduced-motion behavior. It does not implement slider interaction. Set `--diffusion-accent`, `--diffusion-track`, `--diffusion-background`, and `--diffusion-foreground` to consume the surrounding theme.
