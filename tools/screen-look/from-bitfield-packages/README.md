# tools/screen-look/from-bitfield-packages/

The bitfield-packages screen-look package at d926b7adb8ca24159ee64f47e7d9cae254f5b641. `moved-from.json` here names every file carried into this tool from it, wherever it landed (under this tool's own paths: the event invitation and morphing ribbon, the adaptive program landing CSS, the editorial page and site looks, the render descriptor resolver, the iOS JSCore mount, the look records `things-to-store-and-run.json`, the plans and tests).

`show/` here holds the originals of ten CSS files that this tool holds in a shorter form (media-review, coss-workspace, candidate-field, creative-workspace, notifications, floating-workspace, app-navigation, action-row, ask-and-list, beautiful-ui-controls). Both are kept until the two are merged; nothing here is wired. A file that cannot load here is held: its name ends in `.held` (the same bytes): components and tests that import the shared UI package or the Runtime Kit.

Not carried: `show/hosted-sign-in.css` and `show/adaptive-program-landing/ProgramArticlesSection.module.css` (never committed in the source, so no receipt can name them), the seven `reference-adaptation-contract.json` files under `plans/` (they name directories on a person's computer), and the generated `built-stored-bytes`, `.bitfield-entry-scope` and `entry-to-package-data-map.json`.
