Browser surface entry material for Talk To People And Companies.

The current panel consumes `decodeOutsideConversationsSurface`, which now returns
the generic record/work graph projection. The panel reads descriptor-provided
records and action descriptors; it does not own backend record-kind, owner, or
status policy.

The full reference-grounded UI rebase remains governed by the June 20 UI rebase
plan. This folder must not reintroduce package-specific backend branches while
that UI work proceeds.
