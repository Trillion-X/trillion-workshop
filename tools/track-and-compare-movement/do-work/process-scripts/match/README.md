# match/ — Court·Ball·Point Match-Perception Process-Job

The court/ball/bounce/line-call/rally/speed tracker family, run as a `motion-analysis` process-job (DATA-selected), sibling to the swing `../perception/` scripts. Emits self-describing perception facts the generic `motion-analysis` record-maker admits with zero court/ball-specific code.

## Why it lives here (was off-plan in `/dev/court-ball-vision/`)

Per plan `2026-06-27-observe-track-score-coach-primitive` line 466 — *perception binaries belong to `motion-analysis` + `process-engine` as process-jobs as DATA*. The swing pipeline already follows this (`../perception/`); the match pipeline was built in a standalone repo and is ported here to match. Vendored third-party model trees (`WASB-SBDT/`, `TennisProject/`, `TennisCourtDetector/`, weights) stay external and are resolved via the `MATCH_VENDOR_ROOT` env DATA (`TrackerDescriptor.env`) — they are NOT package source.

## Key facts (self-describing — L090, each carries `confidence` + `provenance`)

`perception.court.geometry` · `perception.ball.state`/`.position` · `perception.ball.bounce` · `perception.line_call` (IN/OUT/NEEDS_YOUR_CALL) · `perception.rally.events` · `perception.shot.speed` · `perception.player.position` (dense, `log:false`) · `perception.player.coverage` (reduced, `log:true`).

**Log policy (cont.16 trap fix):** dense per-frame kinds (`court.geometry`, `ball.state`, `player.position`) are tagged `log:false` — kept in the `command-output.json` artifact, NEVER exploded into individual log records — so a full-clip dispatch never traps serializing the write-set. Only the consumed, reduced facts (bounce, line_call, rally, shot.speed, player.coverage) persist as records.

**Player stage (DATA-gated):** player detection is OFF by default; set `MATCH_EMIT_PLAYERS=1` (descriptor env) to run it. It reuses the upstream `torchvision` Faster R-CNN directly (the vendored `PersonDetector` wrapper is broken on current torch), projects each player's foot-point through the SAME homography→court-metre seam as the ball, and keeps players within a 6.0m court play-envelope (run-back/run-off) — wider than the 2.0m ball-bounce gate because players legitimately stand behind the baseline.
