# Publish content for discovery

This package owns public document and route projection. It does not own source visibility, authentication, publication lifecycle, scheduling, destination writes or visitor-specific AI work.

## Exports

- `do-work/prepare-content-for-discovery.mjs` exports `prepareContentForDiscovery(input)`, `sectionsFromMarkdown(markdown)`, and `sectionsToMarkdown(sections)`. It accepts one bounded source page with source/document versions, a source-observation time, `complete` plus `requestedCursor`/`nextCursor`, and one route per document. It returns the projected document bytes and BLAKE3 identities plus page models for sitemap, RSS and `llms.txt`. A partial source page stays partial and carries its continuation.
- `do-work/serve-content-for-discovery.mjs` exports `createContentDiscoveryHandler({loadCurrentPublicSnapshot,paths,feed})`, `serializeSitemapXml`, `serializeSitemapIndexXml`, and `serializeRssXml`. The owner callback is called on every GET/HEAD with `{request,path,format,cursor,limit}`. It must resolve current public rights and return either the requested route or a bounded discovery page. The handler has no stale source cache; source failure returns 503. Responses use `Cache-Control: no-store`, disclose `X-Source-Complete`, and provide `Link: rel=next` where the source has a continuation. Sitemap index/page paths and feed/llms paths are configurable; the pure serializers also support existing site aggregate routes.
- `tool:prepare-public-content-for-discovery` is a callable, pure preparation operation. It never publishes or writes to a destination.

## Input and trust boundary

`site` is `{origin,name,language}`. `source` is `{ref,version,observedAt,requestedCursor,complete,nextCursor,documents}`. The source provider must be the existing public List/share owner: its current read enforces visibility and returns the source version and observation time. This package does not treat a boolean or policy string as proof of rights. `requestedCursor` echoes the cursor used to obtain this page, or `null` for its first page. A partial page must provide a different next cursor; repeated cursors fail to prevent loops. Documents have `{ref,version,title,schemaType,openGraphType,description,updatedAt,sections?,bodyMarkdown?,schemaProperties?,citations}`. The timestamp is required and must parse as a date so sitemap and feed dates stay grounded. `schemaType`, `openGraphType` and optional `schemaProperties` come from document DATA, with canonical fields protected. Extra schema claims are represented as safe visible text and JSON-LD; a site shell can reuse the same `schemaProperties`. Sections are heading, paragraph, quote or list data; `bodyMarkdown` is converted by `sectionsFromMarkdown`, and `sectionsToMarkdown` serializes body-only Markdown for a site shell. Public citations are `{url,label}` and must use HTTPS; an empty citation list is valid. `routes` is a page-sized array of `{documentRef,path}`.

The source/visibility owner must provide its current public view and a genuine versioned page. This code checks shape, completeness, pagination, IDs, versions, routes and public citation URLs; it cannot authenticate a string supplied by an untrusted caller. The owner callback is the rights boundary. It must not provide private sources, stale visibility or a fabricated all-documents snapshot. Continuation cursors come from that same owner and are not fabricated by this projection. Internal row references never appear in public HTML, feeds, JSON-LD, `llms.txt` or the returned public manifest.

Every document in the input page must have exactly one unique origin-relative path. Only HTTPS origins are accepted. Cross-origin and non-canonical paths, duplicate document IDs/routes, known source-version sentinels, invalid dates and inconsistent completion/cursor state fail closed. Source text is rendered through the existing `export-documents-to-files` structured writer's escaped operations; raw HTML is never accepted. JSON-LD type and visible fields come from document/site DATA. The existing `ai-readiness` helpers complete canonical/date metadata and derive Markdown from the served bytes. The sitemap index advertises the current page and its next continuation URL; each sitemap page response also exposes its next cursor in a `Link` header.

## Dependency closure

`part.json` names the callable public exports. The callable descriptor declares the complete runtime file closure: this package's do-work files, the content identity module, the pure `public-page-projection.mjs` module, its underlying structured page implementation, AI readiness conversion/audit helpers and `@noble/hashes`. The read-only host import resolves the same modules and dependency owners without pulling in the page writer's CLI filesystem imports. It has no brand-specific code, fixed domain, scheduler or network dependency.

## Checks

Run `node --test tools/publish-content-for-discovery/test/*.test.mjs` from the Workshop checkout. The controls cover two unrelated origins, changed source versions, withdrawn visibility, retry, partial pages, escaping, source provenance, route validation and visitor serving.
