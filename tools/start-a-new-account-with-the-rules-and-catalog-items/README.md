# tools/start-a-new-account-with-the-rules-and-catalog-items/

Start a new account with the rules and catalog items Trillion does for everyone until the person changes them.

This folder has no row yet. Its old Trillion files are in `from-old-trillion/`: the bytes of tag `old-trillion-before-worker-retire`, under their old paths. `from-old-trillion/README.md` says which load here and which are held until what they import is here. Wiring them into a row is adapting them, in a commit that names `moved-from.json`.

`event-sources.json` is live: the 11 event sources (19 events) of old Trillion's `records/workshop-event-source-records.json`, the same bytes, which the engine reads to hand an account its each-event rules only while the source's vendor is connected.
