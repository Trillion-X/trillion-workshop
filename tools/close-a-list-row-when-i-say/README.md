# tools/close-a-list-row-when-i-say/

Close a list row when I say in my own message that I already did the thing, but only when the answer is a clear yes.

This folder has no row yet. Its old Trillion files are in `from-an-older-version/`: the bytes of tag `old-trillion-before-worker-retire`, under their old paths. `from-an-older-version/README.md` says which load here and which are held until what they import is here. Wiring them into a row is adapting them, in a commit that names `moved-from.json`.

The decision is ported as steps a workflow runs (src/said-done.mjs): `saidDoneAsks` (the question for each open row the message names, pure), `saidDoneVerdict` (what one answer means: settle, leave, or hand on, pure), and `weighSaidDone` chaining them with the owners passed in. DATA is `src/said-done.json`. Tests: `test/said-done.test.mjs` (the 8 old outcomes) and `test/said-done-steps.test.mjs` (6 step tests), 14 pass. Exposed as tools (Nov 20 2026): `tool:name-the-open-rows-a-message-names` (`do-work/name-the-open-rows.mjs`, the question per named row) and `tool:decide-what-a-said-done-answer-means` (`do-work/decide-said-done.mjs`, what one answer means), rows in `records.json` with container invokes, read through `what-this-tool-does-and-how-to-run-it.json`, with kits under `kits/`; tested in `test/said-done-tool.test.mjs` (4 tests). Settling the row and the hand-off are the lists road and the hand-off tool, called by the workflow. Not yet wired: no workflow recipe runs these steps yet, and no wake on a row change calls them, so a message through the door does not close a row yet.
