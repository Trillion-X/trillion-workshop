# Coordination Session

Generic coordination-session lifecycle and catalog operations. Open purpose, mode, lifecycle, access, recommendation, and cross-offer descriptors remain data. Calendar availability, workflows, due windows, identity, permissions, membership, and projections stay delegated to their package owners by reference.

The declared lifecycle target dispatches explicit create, update, reschedule, fork, merge, cancel, supersede, confirm, no-show, close, and feedback requests to the corresponding pure implementation. It does not persist or authorize effects. The five declared suites cover the dispatch family and retained catalog/runtime-context contract. Elapsed-time ownership remains with `notice-when-something-shows-up`; the retired clock package is not restored during consolidation.

`materializeOrganizerEvent` builds a preview from owner-supplied event and group identities. It preserves capacity in the reservation owner's policy shape, keeps display labels separate from identity, validates local date ranges and web routes, and returns no publication permission. The caller supplies a retained 128-bit hexadecimal event identity; React render IDs and short label hashes are unsuitable. All six declared suites pass.
