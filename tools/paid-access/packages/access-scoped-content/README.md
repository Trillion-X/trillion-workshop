# access-scoped-content

Generic package source for mounting exact owner-provided content surfaces from
revision-bound, owner-ready access projections. It never calculates grants or
infers a renderer from MIME, URL, provider, transcript, or object-store fields.

This folder is package implementation source material. Runtime truth comes from the selected Bitfield root's log-owned package state after admission, not from this source folder by itself.

See `reference-grounded-screen-contract.md`. Production visual and live
revocation proof remain open until the Tribes T7/T8/R6 wave.
