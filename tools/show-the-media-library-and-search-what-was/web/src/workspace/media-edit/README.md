# src/workspace/media-edit

The media editor's side panels and cut-editing parts, mounted by `src/workspace/media-edit-screen.tsx`. The screen lays them out by its own width (container queries, never the window's): narrow, the player, a sideways strip of clips and the tools stack; from 640px the tools sit beside the player; from 1040px the clips are a column on the left, the player in the middle and the tools on the right, with the timeline across the bottom.

## Files

| File | Purpose |
|------|---------|
| `panels.ts` | THE insertion point: the ordered `PANELS` list. Adding a side panel is one import + one row here. |
| `panel-types.ts` | The panel contract (`MediaEditPanel`, `MediaEditPanelProps`, `MediaEditPanelContext`, `MediaEditClip`, `definePanel`); a panel's optional `preview(state, context)` adds fields to the player's composition (captions in their style). |
| `cut-list.ts` | The cut as an ordered clip list and every change to it: `splitAt` (at the playhead), `removeRange` (take a stretch of cut time out; what is left of each clip stays, by range complement), `insertRange` (a stretch of a file as a new clip; one already used is refused), `moveTo` (drop a clip at the nearest boundary), `clipAt`, `cutOffsets`; and `cutComposition`, the track lanes the timeline draws (picture, captions and text, and every panel's laid-over layers). |
| `track-lanes.json` | DATA: each track lane's name, role, colour tone and row sharing, in screen order. |
| `cut-player.tsx` | `CutPlayer`: the shared live player (`parts/ui` LiveCompositionPreview) playing the whole cut from its original files, or only the selected clip, with what the panels add (`additions`, such as captions drawn in their style) over the whole cut; reports the playhead in cut time. Marked `data-media-edit-panel="preview"`. |
| `cut-timeline.tsx` | `CutTimeline`: the timeline's actions (DATA handed in, each `{ id, label, icon, group, run }`: drawn as its icon with its name in the shared tooltip, groups split by a thin rule, one row that scrolls sideways when narrow) over the shared track lanes (`parts/media-composition` EditTrackLanes): ruler scrub, clip drag to reorder, edge trim. Marked `data-media-edit-panel="timeline"`. |
| `use-measured-lengths.ts` | `useMeasuredLengths`: a clip opened with no known length is measured from its own file in the browser and the length is kept as the file's `duration` fact, so Media and every AI see it. |
| `transcribe-panel.tsx` | The Words panel (`transcribePanel`): the selected clip's kept transcript in the shared transcript reader, word by word; choosing a word plays from it, "Use only this part" trims the clip to a passage, and "Transcribe" works out the words of a clip that has none (`../media-transcribe.ts`). An uploaded clip is transcribed by itself: while those words are still being made (or tried again after a failure) the panel says "Your words are being made" and looks again every 5 seconds, and when making them failed for good it says so with "Try again" (`wordsOfRecording`). Outer element carries `data-media-edit-panel="transcribe"`. |
| `captions-panel.tsx` | The Captions panel (`captionsPanel`): "Make captions from the words" reads each clip's kept transcript (`/work/api/namespace/results/<file>?kind=transcript`) and gathers the words said in the kept part of each clip into caption lines on the cut's time, the way the chosen style gathers them (`caption-lines.ts` `captionLinesForEdit`); each caption's words, times and place are edited in the shared timed text editor (`parts/ui/show/selection/timed-text-editor.mjs`); the caption style is picked from `parts/media-composition/read-data/caption-styles.json` in the shared `StyleChoices` cards, each sample drawn in the style's own font and colours with the person's own words. Under the cards the shared inspector (parts/ui TuningPanel over the catalog's `settings` rows, with a CaptionSample of the style) changes any detail: font, size, bold, italic, colours, outline, shadow (x, y, blur, spread, colour, opacity), place, how words light up, words per caption (captions made from the words are gathered again). Saves the style under `panels.captions.style` (an id, or the style's own row `{ id, ...details }`); `preview()` draws the captions in the style over the player; `edl()` burns the editor's captions in it through `caption-styles.mjs` `captionAss`. Outer element carries `data-media-edit-panel="captions"`. |
| `look-panel.tsx` | The Colour panel (`lookPanel`): for the selected clip's file, looks from `parts/media-composition/read-data/looks.json` (one style at a time, colour grades stack in the order picked), adjustment sliders, a draggable frame window with fit, zoom and mirror (shared `FrameWindow`), "Match colour to another clip", and timed colour changes over the whole video. Saves ids and numbers under `panels.look`; `segment()` / `edl()` turn them into render fields through `looks.mjs`. Every picture clip is placed in the chosen frame, never stretched. Outer element carries `data-media-edit-panel="look"`. |
| `make-panel.tsx` | The Make panel (`makePanel`): lists the styles in `parts/media-composition/do-work/make-pictures-and-sounds.json`, takes the words a style needs (read from its `input_schema`) and the selected clip's second under the playhead, runs `tool:make-<style>` through `../workshop-tool-api.ts` (one synchronous run), and shows each picture or sound in the files the run kept. Results are kept in the person's files under Made by tools (the Layers panel's Made with tools shelf drops them into the video) and remembered under `panels.make`. A missing connection is named in plain words. Outer element carries `data-media-edit-panel="make"`. |
| `send-to-editor.tsx` | The Send to editor panel (`sendToEditorPanel`): sends the saved edit to Premiere Pro or DaVinci Resolve as a timeline file whose clips open from the person's Trillion files on their computer (`/work/api/media/send-to-editor` → `tool:send-edit-to-editor`), offers it to download or open in Files with what the timeline could not carry, and takes the exported video back as the edit's finished version (uploaded into `/edits/<id>/`, then `/work/api/media/finished` → `tool:attach-finished-video`). Editors, computers and speeds are DATA in `../../editor-handoff.json`. Outer element carries `data-media-edit-panel="send-to-editor"`. |
| `layers-panel.tsx` | The Layers panel (`layersPanel`): sounds under the cut (music, voice-over, sound effects: start, stretch of the file, volume, fades, duck under speech) and pictures over it (picture in picture, logo, b-roll: start, length, position, size, opacity, back-to-front order) from the person's own files, plus a Made with tools shelf to click or drag in; "Even out the loudness". Reads the library only when opened. Saved under `panels.layers`; `edl()` turns usable layers into render fields through `parts/media-composition/read-data/layers-to-edit.mjs` (the same translation `tool:mix-sound-layers` / `tool:layer-pictures-over-video` use); `layers()` feeds the preview and the Pictures over the video / Sounds lanes; `changeLayer()` takes timeline trims/moves and preview drags; `fromSavedEdit()` opens an older edit's single music bed as its first sound. A layer with unusable numbers is named with the reason and left out until fixed. Outer element carries `data-media-edit-panel="layers"`. |
| `layer-presets.json` | DATA: the kinds of sound and picture layer the Layers panel adds (label, icon, file families, starting values) and the loudness level. |

## Key Types / Functions

| Type | Shape | Role |
|------|-------|------|
| `MediaEditPanel<State>` | `{ id, label, icon, Panel, edl?, segment?, fromSavedEdit?, layers?, changeLayer? }` | One side panel row. `edl(state, context, edit)` adds top-level render fields given the edit so far (panels chain in order, so lists grow instead of being replaced); `segment` adds per-clip render fields; `fromSavedEdit(edl)` reads its choices from an edit saved before it existed; `layers` lays sounds/pictures over the cut for the preview and timeline; `changeLayer(state, id, change)` applies a timeline trim/move or preview drag. |
| `MediaEditLayer` | `{ id, lane, label, identity, bytes, mediaKind, plays: 'sound'\|'picture', start, in, out, volume?, x?, y?, scale?, opacity? }` | A laid-over sound or picture; `start` cut time, `in`/`out` file seconds, `x`/`y` the picture's centre and `scale` its width as shares of the frame; `lane` names a track-lanes.json row. |
| `MediaEditLayerChange` | `{ start?, in?, out?, x?, y?, scale? }` | One change to a laid-over layer. |
| `CutLayer` | `MediaEditLayer & { panel }` | A layer with the panel that owns it, as the lanes and player take it. |
| `layersPanel` | `MediaEditPanel<LayersState>` (id `layers`, label Layers) | `LayersState = { sounds: SoundLayer[], pictures: PictureLayer[], loudness? }`. |
| `MediaEditPanelProps<State>` | context + `{ change, select, seek, setCaptions, setStatus, panelState, setPanelState }` | What a panel component receives. |
| `MediaEditPanelContext` | `{ editId, title, clips, selected, active, timelineStart, activeTimelineEnd, total, playhead, ratio, dimensions, captions }` | The current cut, read-only. |
| `definePanel(row)` | `MediaEditPanel<State> -> MediaEditPanel` | Keeps a row's State type without casts. |
| `splitAt(clips, seconds)` | `-> { clips, selected }` | Two clips where one was, at a moment of cut time; refuses the edge of a clip. |
| `removeRange(clips, from, to)` | `-> MediaEditClip[]` | The cut with a stretch of cut time taken out. |
| `insertRange(clips, source, range, at)` | `-> MediaEditClip[]` | A stretch of `source`'s file (its own seconds) as a new clip at position `at`. |
| `moveTo(clips, index, seconds)` | `-> { clips, selected }` | A clip moved to the nearest boundary to a moment of cut time. |
| `cutComposition(clips, words, layers)` | `-> MaterializedComposition` | The lanes EditTrackLanes draws; lane clip ids read back with `readLaneClipId`. |
| `CutPlayer` | `{ clips, selected, selectedStart, dimensions, layers, onLayerChange, scope, onScope, onTime, seek }` | The one player. |
| `CutTimeline` | `{ composition, playhead, selectedClipId, actions, marked, onSeek, onSelect, onTrim, onMove, children }` | The timeline. |
| `TimelineAction` | `{ id, label, icon, group, run, disabled?, emphasis? }` | One timeline action as DATA: a Lucide icon name and the group it sits in. |
| `useMeasuredLengths(clips, apply, tell)` | `-> boolean` (still measuring) | Lengths read from the files themselves, never guessed. |
| `transcribePanel` | `MediaEditPanel` (id `transcribe`, label Words) | Keeps nothing in the edit; reads and makes the recording's own `transcript` result. |
| `lookPanel` | `MediaEditPanel<LookPanelState>` (id `look`, label Colour) | `LookPanelState = { clips?: { [file]: { looks?, adjust?, framing?, match? } }, timed?: { adjustments?, looks? } }`. |

## How a panel's choices are kept

- The panel's own choices are saved under `edit.panels[<panel id>]` by `/work/api/media/edit` and restored on reopen; a panel with nothing saved yet is asked `fromSavedEdit(savedEdl)`.
- `segment()` results ride on each rendered clip; `/work/api/media/render` keeps them only for the segment playing the same clip, and always takes where the clip plays from from the checked clip.
