## Translation Boundary

- Human terms: phase label, field label, result label, next action, unavailable.
- Banned terms: Envelope, slot, descriptor, target, workflow definition, state ref, revision, package, payload.
- DATA supplies every visible label and action; source never branches on phase or protocol tokens.

## Shared Primitive Plan

- Reuse `ui` Card, Container, Text, Badge, Button and `PlaceableSurfaceHost`.
- Reuse `screen-look` tokens through those primitives. No package-local media/player primitive exists.

## Render-State Matrix

- Empty/unavailable: missing descriptor fails closed with one setup message.
- Sparse: one phase, one field, one action.
- Dense: many fields and embedded surfaces remain ordered by descriptor.
- Loading: unavailable until the selected descriptor resolves; no fabricated defaults.
- Error: denied transition or failed action keeps current state visible.
- Revoked: selected state/descriptor update removes unavailable owner surfaces.
- Mobile/desktop: wrapping cards/actions and owner surfaces preserve readable order.
